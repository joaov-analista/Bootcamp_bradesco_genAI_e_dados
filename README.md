# Bootcamp Bradesco - GenAI e Dados
Este repositório contém todos os projetos realizados durante o bootcamp do [Bradesco na DIO](https://web.dio.me/track/bradesco-genai-dados)

#  Sobre o Bootcamp
Esse Bootcamp é uma parceria da DIO com o Bradesco com duração de 52 horas.

O curso ensina várias ferramentas importantes para o mercado, como:
IA Generativa
Machine Learning
LLMs
Agentes de IA
Técnicas de Engenharia de prompt 
Bancos de dados relacionais
Business Intelligence
Python

Todos os projetos realizados podem ser encontrados [aqui](https://github.com/joaov-analista/Bootcamp_bradesco_genAI_e_dados/blob/main/Projetos)
